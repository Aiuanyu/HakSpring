安頓摎啟用指引

  1. 1

    落載 APK 安裝檔

    撳頂高「落載 Android APK」撳鈕。瀏覽器係講出現「檔案可能具備危險性」這隻系統預設警示，請點擇「仍要下載」（這係 Android 針對非 Google Play 管道 APK 个例行提醒）。

  2. 2

    允許安裝外部來源應用

    點開落載完成个 APK。係講系統擋核安裝，請點擇彈出來視窗个「設定」，打開「允許來自此來源的應用程式」，續等轉去點擇「安裝」。

  3. 3

    在系統啟用「客源翠企盤」

    入去手機「設定」→「系統」→「語言與鍵盤（抑係輸入法）」→「螢幕鍵盤（虛擬鍵盤）」，尋著淡紫灰鍵帽圖示个「客源翠企盤」並摎開關切換做開啟。

  4. 4

    切換輸入法開始打字

    打開任何文字輸入框（像 LINE 還係頂高試驗區），撳螢幕右下角鍵盤圖示（抑係長撳空白鍵），切換做「客源翠企盤」，斯做得開始用全客話打字！

  5. 5

    自由切換六大腔調

    在企盤頂高長撳空白鍵，還係點擇企盤齒輪入去「設定」，就做得自由擇用四縣、南四縣（美濃音）、海陸、大埔、饒平（卓蘭／桃園）、詔安這兜腔別。

  1. 1

    落載並解開壓縮檔

    落載 HakSpring-Kipan-macOS.zip，雙擊解壓縮後會得著 HakSpring-Kipan.app 應用程式。

  2. 2

    搬移至輸入法系統目錄

    打開 Finder，在頂頭擇單點「前往」→「前往資料夾...」（還係撳快捷鍵 Command + Shift + G），輸入路徑：
    ~/Library/Input Methods
    撳 Enter 入去過後，摎 HakSpring-Kipan.app 拖放落這隻資料夾裡肚。

  3. 3

    【盡重要】滑鼠右鍵打開（繞過 Apple Gatekeeper 檢查）

    ⚠️ 特別說明：因爭目前社群封測階段還吂花每年 $99 美元向 Apple 買商業開發者簽章，直接連撳兩擺打開會出現「無法打開，因為它不是由識別的開發者發送」。

    請定著恁仔做：在 HakSpring-Kipan.app 頂高撳滑鼠右鍵（還係撳等鍵盤 Control 鍵點撳），擇擇單最頂項「打開」。在彈出來个安全確認對話框肚，點擇「打開」斯做得成功放行！

  4. 4

    去系統設定加入輸入方式

    打開 Mac「系統設定」→「鍵盤」→「文字輸入」→ 點擇「輸入方式」脣項个「編輯...」撳鈕。撳左下角 + 號，在語言清單（客語還係繁體中文）尋著「客源翠企盤」，點擇「加入」。

  5. 5

    登出並重新登入（還係重新開機）

    加入過後，建議登出 macOS 使用者帳號並重新登入（還係重開機）。右上角擇單列就會出現客源翠企盤烏底白字「客」鍵帽圖示，點擇就做得啟用！快捷鍵：Control + 數字鍵（1..8） 做得手動帶調號；反白擇取文字撳 Control + Command + T 做得觸發雙行重組。

打字說明摎功能設定

6 種打字方式（繼承上游核心）

  • 免聲調、音節打一半、單淨打頭字母：聲調毋使打，音節乜做得打一半，還係單淨打頭字母。像 hag2fa55、hag2fa、hagfa、hagf、hf 全部尋得著「客話」。
  • 整句共下打：規句連打乜做得，企盤會自家斷音節。像打 ngaioisiidfan 會尋著「𠊎愛食飯」。
  • 手動斷音節（連字符）：想愛自家斷音節，就打連字符 -。像打 zui 會尋著「最」摎「追」，打做 zu-i 正會尋著「注意」摎「主意」。
  • 事後補打聲調：打好字母正打聲調數字，企盤會換做聲調符號（像 hag2fa55）；聲調打毋著，撳一下刪字鍵過打一擺就做得（macOS 亦支援 Control + 數字鍵）。
打法類型 輸入範例 候選結果
帶調／無調／縮寫 hag2fa55、hagfa、hagf、hf 客話
整句連打 ngaioisiidfan 𠊎愛食飯
連字符斷音節 zu-i（對比 zui） 注意、主意（最、追）

輸入系統

  • 用企盤頂高个工具列切換客語拼音（HagPinPlus）摎英文模式。
  • 支援教育部臺灣客語拼音方案（HagPinPlus），四縣、南四縣、海陸、大埔、饒平、詔安六腔全部做得順暢打字。
  • 未來乜會陸續加入客語白話字（PFS）等更多書寫系統支援。

羅馬字轉換器（漢羅切換）

  • 空白鍵右邊个轉換鍵，做得切換漢字模式摎羅馬字模式。預設係漢字模式，擇候選詞會送出漢字。
  • 標點符號乜會跈等換：漢字模式用全形，羅馬字模式用半形。

自動大寫（大寫／細寫）

  • 打開「自動大寫」，一句个頭一个字母會自動變大寫，Shift 鍵會變色反白；關起來就全部打細寫。
  • 連續撳 Shift 兩下係 Caps Lock，會一路打大寫，過撳一下就解除。

單手模式

  • 長撳工具列个企盤圖示，擇左手還係右手，企盤就會移去該片。
  • 邊脣个撳鈕做得「換邊」，還係轉去「一般」。

3 種候選詞顯示

  • 在「設定」→「候選詞顯示」擇用：漢羅對應（共下顯示，用轉換鍵決定送出）、漢羅合用（分兩格，擇哪一格送哪一種）、羅馬字（單淨顯示並送出羅馬字）。
  • 說明：企盤介面講著个『諸夏字』，同「漢字」同義。

打字設定

  • 當在打个字放第一格：候選詞頭一格就係你打个羅馬字，辭典無收个詞乜做得直接送出（關起來時撳 Enter 亦可送出）。
  • 雙書寫標註：漢字摎羅馬字共下送出，像 客話 (Hag-fa)。
  • 音節分隔摎自動閬縫：音節分隔做得擇連字符（hag-fa）、閬縫（hag fa）還係無隔開（hagfa）；打開「自動加入閬縫」送出羅馬字後會自動加空格。

連續建議詞

  • 擇一隻詞之後，企盤會建議後一隻：像擇「恁」，「早」就會出現（恁早！）。
  • 辭典無收个詞句，打過一擺就會記下來，下擺會在建議裡肚出現。

辭典管理摎尋詞

  • 預設包含教育部臺灣客語常用詞辭典、客家委員會認證詞彙等語料。
  • 「詞庫」→「辭典管理」做得開關各腔辭典，亦有用「尋字」功能用漢字還係羅馬字查詞。

自訂詞庫

  • 辭典無个詞，做得在「詞庫」→「自訂詞庫」撳 ＋，輸入羅馬字摎漢字。
  • 乜做得匯入無標題个 CSV：第 1 欄羅馬字，第 2 欄漢字。

學習紀錄

  • 企盤會記等擇過个詞摎打過个詞句，輒輒用个排較頭前；在「詞庫」→「學習紀錄」做得排序還係刪忒。
  • 有漢字个紀錄做得直接加入自訂詞庫（Android 撳該項个 ＋、iOS 向右片滑）。

字型摎外觀

  • 「設定」→「字型設定」提供支援客語特殊用字个字型。
  • 「主題」頁做得調色目、撳鍵大小摎形狀，乜支援自訂背景相片，逐項都做得恢復預設。

資料摎隱私

  • 自訂詞摎學習紀錄全部放在手機裡肚，毋會送去網路。
  • 換手機進前，記得在「詞庫」→「備份復原」匯出；Android 摎 iOS 都做得匯入。

客語通用轉換器

  • 本站另有線上轉換工具（並列格式轉換器／首頁羅馬字轉換工具），摎企盤用共一个核心，結果一致。

常見問題摎目前限制

企盤敢會紀錄還係搜集𠊎打字个內容？

絕對毋會！客源翠企盤 100% 本機離線運作，無連接任何外部雲端伺服器，乜無請求網路存取權限。你輸入个字句、自學詞庫摎打字習慣，全部單淨保存在你自家个手機抑係電腦裡肚，請安心創作。

iOS（iPhone / iPad）摎 Windows 敢有支援？

目前社群封測初期優先專注在 Android 摎 macOS。iOS、Windows 摎 Linux 版本當在該規劃排程肚，等穩定過後會陸續開放測試。

打字係講尋毋著特定詞、還係音讀有毋著愛仰般辦？

這係社群封測盡需要大家𢯭手个所在！係講堵著缺字、候選排序怪怪、還係音讀需要勘誤，歡迎隨時透過下背回饋表單還係 GitHub 回報，𠊎兜會持續校對收納入客源翠詞庫。
