安頓摎啟用指引

  1. 1

    落載 APK 安裝檔

    點擊上方「落載 Android APK」按鈕。瀏覽器若出現「檔案可能具備危險性」之系統預設警示，請點選「仍要下載」（此為 Android 針對非 Google Play 管道 APK 之例行提醒）。

  2. 2

    允許安裝外部來源應用

    點開下載完成之 APK。若系統阻擋安裝，請點選彈出視窗之「設定」，開啟「允許來自此來源的應用程式」，接著返回點擊「安裝」。

  3. 3

    在系統啟用「客源翠企盤」

    進入手機「設定」→「系統」→「語言與鍵盤（或輸入法）」→「螢幕鍵盤（虛擬鍵盤）」，尋著淡紫灰鍵帽圖示个「客源翠企盤」並將開關切換為啟用開啟。

  4. 4

    切換輸入法開始打字

    打開任何文字輸入框（例如 LINE 或上方試驗區），點擊螢幕右下角鍵盤圖示（或長按空白鍵），切換為「客源翠企盤」，即可享受全客語打字！

  5. 5

    自由切換六大腔調

    在鍵盤上長按空白鍵，或點選鍵盤齒輪進入「設定」，即可自由選用四縣、南四縣（美濃音）、海陸、大埔、饒平（卓蘭／桃園）、詔安等腔別。

  1. 1

    落載並解開壓縮檔

    落載 HakSpring-Kipan-macOS.zip，雙擊解壓縮後會得著 HakSpring-Kipan.app 應用程式。

  2. 2

    搬移至輸入法系統目錄

    打開 Finder，在頂部選單點「前往」→「前往資料夾...」（或按快捷鍵 Command + Shift + G），輸入路徑：
    ~/Library/Input Methods
    按 Enter 進入後，將 HakSpring-Kipan.app 拖曳放進這隻資料夾裡肚。

  3. 3

    【極重要】滑鼠右鍵打開（繞過 Apple Gatekeeper 檢查）

    ⚠️ 特別說明：因目前社群封測階段尚未花費每年 $99 美元向 Apple 購買商業開發者簽章，直接連按兩下打開會出現「無法打開，因為它不是由識別的開發者發送」。

    請務必這樣做：在 HakSpring-Kipan.app 上按滑鼠右鍵（或按住鍵盤 Control 鍵點點擊），選選單最頂項「打開」。在彈出的安全確認對話框中，點選「打開」即可成功放行！

  4. 4

    至系統設定加入輸入方式

    打開 Mac「系統設定」→「鍵盤」→「文字輸入」→ 點選「輸入方式」旁个「編輯...」按鈕。點左下角 + 號，在語言清單（客語或繁體中文）找到「客源翠企盤」，點選「加入」。

  5. 5

    登出並重新登入（或重新開機）

    加入後，建議登出 macOS 使用者帳號並重新登入（或重開機）。右上角選單列即會出現客源翠企盤黑底白字「客」鍵帽圖示，點選即可啟用！快捷鍵：Control + 數字鍵（1..8） 可手動帶調號；選取文字按 Control + Command + T 可觸發雙行重組。

常見問題摎已知限制

企盤敢會紀錄或搜集𠊎打字个內容？

絕對毋會！客源翠企盤 100% 本機離線運作，無連接任何外部雲端伺服器，無請求網路存取權限。你輸入个字句、自學詞庫與打字習慣，全部僅僅保存在你自家个手機或電腦裡肚，敬請安心創作。

iOS（iPhone / iPad）摎 Windows 敢有支援？

目前社群封測初期優先專注於 Android 摎 macOS。iOS、Windows 摎 Linux 版本正在軟體架構排程中，待穩定後會陸續開放測試。

打字若搵毋著特定詞、或音讀有誤要仰般辦？

這係社群封測最需要大家幫忙个地方！若遇到缺字、候選排序怪怪、或音讀需要勘誤，歡迎隨時透過下方回饋表單或 GitHub 回報，𫣆俚會持續校對收納進客源翠詞庫。
