# 次方言補音（`data/sub-dialects-fill/`）

認證四縣詞條無標【南】，毋係「南北共樣」，係官方漏標（尤其高級、形容詞副詞个仔尾）。
這个資料夾放程式推導个南四縣音，係原詞條个**附表**：以「來源＋編號」對到認證詞條，原始資料毋動，也毋算另一本詞典。

## 推導順序

前一層有結果就停：

1. **教典南四縣**：詞目共樣就用教典个音（`gip`）。教典讀音對原始 CSV 拆（`load_gip_readings`，見 `data/annotations.md`），音節數摎北四縣無共樣个毋用。教典有同形異義時，揀摎逐音節推導最近个讀音。單字詞个教典音摎推導無共樣，記做 `gip-check`，愛人工確認。
2. **逐音節**（`syllable`）：
    - 詞尾「仔」照詞性：形容詞、副詞 → `é`，名詞 → `è`（`zai`）
    - 字級對照：由已標南音个認證詞、教典四縣／南四縣共詞，學「這隻字北讀 X、南讀 Y」，出現 1 擺以上、佔 8 成以上正用（`table`；20261021 由 2 擺降做 1 擺，交叉驗證字級對照 96.5%→96.3%、整條全對 78.0%→78.8%）。斜線連等个音節（同詞多音，例：欣賞 `hím/hiún`）算共一隻字位置
    - 系統規則：舌根音、喉音、零聲母 + `-ien/-ied` → `-ian/-iad`（`rule-ien`）
    - 以上都無：音節無證據（`same`）。**有這種音節个詞條算推毋出**，毋寫進附表，另外列在 `待審-南四縣`（毋權充北四縣音）。

## 美濃

**認證**以南四縣音做底（認證原標，抑係上背南四縣附表推得出來个）；**教典**以教典南四縣个讀音做底（教典四縣个詞用共樣詞目對過去，95% 對得著）。教典南四縣無收、淨教典四縣有个詞（例：芋卵，南四縣教典淨收芋卵仔），就由北四縣用逐音節規則先推南四縣、再推美濃（`來源檔` 寫 `教典四`、`南四縣來源` 寫 `教典四縣推導`；有音節無證據就跳過）。再：

1. 字級對照：由認證已標个美濃音學（例：卵 `lòn→nòn`、等 `dèn→nèn`、國 `guèd→gièd`）。認證淨 33 條美濃音，規則少。
    - **美濃音愛摎同一隻詞目對應**（20261029）：`js/variant-parser.js` 愛將「同義異形詞」（好額【有口（有發）】，括號內係南四縣个別種講法）摎「美濃音屬南四縣詞」（佢兜人【佢等】 `ǐ dén (ǐ nén)`，`ǐ nén` 係「佢等」个美濃音）分清楚；`meinung_table` 淨用 `meinung_word == word` 个詞條。以前（6864dd8～）毋分，美濃附表有 512 列被污染（好處 → `iū cu`、額頭 → `bòd těu`、寄 → `giu`），這下認證 54 條美濃標記詞，逐音節都摎底音有聲母抑韻母共樣（`tests/build_subdialect_fill_test.py` 3c 守著）。
2. 24 調一律改 33 調（`á` → `ā`）。這條係平哥个規則；**認證標个美濃音聲調還係寫 24**（例：國家 `gièd gá`），所以資料驗毋著。
    - <sup>20261024 18:26</sup>網站已改成直接用規則：設定「美濃腔」打開，四縣、南四縣个 24 調註 ruby 33（`main.js` `getSandhiHtml`），所以 `美濃.web.json` **淨收詞彙性差異**（用著字級對照个，認證 83、教典 253 鍵）；純 24→33 个毋使存。企盤讀个附表（`美濃.json`）無變。

認證南四縣推毋出个詞條，美濃乜跳過。南四縣詞括號內係同義詞（A 類，好額【有口（有發）】，共 9 條）个詞形摎北四縣無共樣，美濃**毋推**（平哥 20261029）。認證已標美濃音个詞條毋補。推導層一律 `系統規則`。教典列个鍵用「腔＋詞目」：`來源檔` 寫 `教典南`、`編號` 空白。

## 附表欄位（摎企盤 dialects 線約定，20261018）

企盤建置腳本直接讀 `南四縣.json` 个 `entries`：

| 欄位 | 內容 |
|---|---|
| `來源檔` | 認證檔名，例 `113四高`；摎 `編號` 合起來對到原詞條 |
| `編號` | 認證編號，例 `1-23` |
| `詞目` | 詞目漢字（冗餘，換年度時拿來回找） |
| `北四縣` | 原詞條个北四縣標音（對照用） |
| `讀音` | 推導个讀音：HagPinPlus 調符、音節空白分隔，摎認證標音共樣格式（認證原有个括號同義詞照留），無數字調 |
| `變體` | 陣列：`南`／`美濃`／`卓`／`桃`，一筆做得有幾隻（卓桃共用就兩隻都標） |
| `推導層` | `教典南四縣`／`字級對照`／`系統規則`／`人工` |
| `待確認` | `true`：單字詞，教典音摎逐音節推導無共樣（可能同形異義） |
| `同北四縣` | 推導結果摎北四縣共樣 |
| `逐音節` | 逐音節方法（`table`／`zai`／`rule-ien`），覆核用 |

一條詞有用著幾種逐音節方法時，`推導層` 取較弱个：有 `zai`／`rule-ien` 就係 `系統規則`，全部 `table` 正係 `字級對照`。

教典詞條（之後做）个鍵用「腔＋詞目」，因為教典 `idx` 會位移。

網站在變體區塊加「南」「美」，後背標「推導」；認證原標个毋改。美濃腔**預設毋顯示**，愛在全域設定開「美濃腔」；開了以後 24 調註 ruby 33，詞彙性差異个詞（認證、教典）加「美」一列。

## 準確率

`python3 scripts/build_subdialect_fill.py --eval`：拿已標南音个認證詞條做五摺交叉驗證（字級對照毋看自家）。

| 方法 | 準確率 |
|---|---|
| 字級對照（逐音節） | 96.3% |
| 仔照詞性（逐音節） | 92.9% |
| 教典南四縣（整條） | 83.7%（毋著个大多係認證摎教典本身讀音無共樣） |
| 整條全對 | 78.8% |

（準確率係篩忒「推毋出」以前量个。）

注意：考卷係「已標南音」个詞，這兜係因為南北無共樣正標个，所以「照北四縣」（`same`）在考卷肚準確率當低，無代表無標个詞條。

## 更新流程

`python3 process_all_data.py`（抑係 `--only-supp`）最尾會自動重建。全部係產生个檔，毋好手改。

## 人工審音

推毋出个（`待審-南四縣`）摎單字詞待確認个（`待確認`），用審音工具人工定音：

1. `python3 scripts/build_review_queue.py`（`process_all_data.py` 最尾乜會跑）產生 `review/queue.json`。毋放 `data/`：網站毋讀這个檔。
2. 本機伺服器開 `review-readings.html`。三隻分頁：
    - **依字歸組**：待定音節照（字、北音）歸組（「仔」再分詞性），一組定一擺，套到組裡全部詞條。先審這隻，效率最高（445 組；出現 2 擺以上个 214 組審完，651 條裡 448 條就定好）。注意同字無共樣意思个（例：空 `kúng`／`káng`），組裡个詞全部會列出來，例外个到「南四縣待審」單獨改。
    - **南四縣待審**：逐條。字組定好个會自動填入，標「字組已定」；做得單獨改（個別詞條優先過字組）。
    - **教典待確認**：教典南四縣讀音摎逐音節推導二擇一。
   候選音係這隻字在教典南四縣、已標南音个認證詞裡个南音，有次數摎出處。進度存在瀏覽器。
3. 按「匯出 CSV」，下載兩个檔，都放 `data/sub-dialects-fill/`：
    - `人工-南四縣.csv`（個別詞條；欄位：來源檔、編號、詞目、讀音、判定、備註、時間、queue）
    - `人工字音-南四縣.csv`（依字歸組；欄位：字、北音、詞性、南音、判定、備註、時間；詞性淨「仔」有）
4. 重跑 `python3 process_all_data.py --only-supp`：判定「採用」个正收，「不確定」照舊。
    - 人工字音當最優先个字級對照，逐音節方法記做 `manual`；整條全部係人工字音，推導層寫 `人工`，摎其他方法混用就取其他方法較弱个。
    - 個別詞條蓋過全部推導，推導層寫 `人工`。
    - 改著 `data/` 愛 bump `data_version.json`。

審音頁會自動讀 repo 裡肚已經有个兩个 CSV（瀏覽器無記錄个正補），換電腦、下一輪乜接得落去。審過个條目重產佇列以後還在，做得轉去改。
