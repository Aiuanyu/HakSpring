# 愛灣語加詞（`data/curated/`）

教典、認證都無收，由愛灣語**依例句出現情形摎個人語感**人工加个字詞。毋係補字典：補字典係用公開資料依規則推導（`data/supp/`），這裡係人工判斷。

- **源頭**：`加詞.csv`（人工維護，毋好直接改 JSON）。欄位：`腔`（四／海／大／平／安／南）、`字`、`客語標音_顯示`、`客語標音_查詢`、`依據`、`判斷說明`。
- **產出**：`python3 scripts/build_curated.py`（`process_all_data.py` 會呼叫）→ `加詞-{腔}.json`、`加詞-{腔}.csv`，格式同補字典。六腔都有檔案，無資料个腔就係淨表頭。
- **分類**：`個人加詞`；`sourceName` 係 `愛灣語加詞{腔}`；`sourceType` 係 `curated`。
- **釋義固定**：`（教典、認證未收；愛灣語依例句出現情形與個人語感收錄，歡迎審查）`。毋寫「程式自動」。
- **輕聲**：顯示欄仿臺語雙 hyphen 寫 `--he`，查詢欄寫 `he0`。
- **優先過擬音**：`scripts/build_supp_dict.py` 讀這个檔，同腔同字已有人工加詞，就毋輸出該字个 `擬音` 列（例：四縣「喺」个擬音 `hì`）。
