# 客語翻譯迭代學習系統

## 📚 系統概述

這是一個**迭代學習系統**，透過不斷的翻譯練習、人工修正、記錄學習心得，來提升 AI 的客語翻譯能力。

整個過程**不需要模型訓練**，而是使用 **RAG（檢索增強生成）** 的方式，讓 AI 在翻譯時參考：
1. 客語詞典（詞庫）
2. 學習心得文件（從修正中累積的經驗）

## 🔄 工作流程

```
┌─────────────────────────────────────────────────┐
│  1. AI 試譯（參考詞庫 + 學習心得）               │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│  2. 使用者逐句修改（提供正確翻譯 + 註解）        │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│  3. AI 比較差異 → 生成學習心得                  │
│     - 詞彙修正記錄                              │
│     - 句型模式提取                              │
│     - 常見錯誤分析                              │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│  4. 更新學習心得文件                            │
└─────────────────┬───────────────────────────────┘
                  │
                  └──► 回到步驟 1（下次翻譯時使用）
```

## 📝 學習記錄格式

### `hakka_learning_log.json`（機器可讀）

```json
{
  "corrections": [
    {
      "id": 1,
      "source_text": "社會中",
      "my_translation": "社會中",
      "correct_translation": "社會裡肚",
      "lesson": "「中」在客語通常翻譯為「裡肚」",
      "category": "詞彙-方位詞"
    }
  ],
  "patterns": [...],
  "vocabulary_updates": {...}
}
```

### `hakka_learning_notes.md`（人類可讀）

Markdown 格式的學習筆記，包含：
- 詞彙修正記錄
- 句型模式
- 常見錯誤分析
- 學習統計

## 🎯 使用方式

### 1. AI 翻譯

AI 會參考：
- 四縣客語詞典（約 9,800+ 詞彙）
- 學習心得文件

### 2. 人工修正

在 GitHub 上編輯翻譯文件，逐句修正：
- 標註錯誤的翻譯
- 提供正確的翻譯
- 加上註解說明原因

### 3. AI 學習

AI 會：
- 比較差異
- 提取學習模式
- 更新學習心得文件

### 4. 循環改進

下次翻譯時，AI 會應用新學到的知識。
