## 一、重點結論

1. **Firefox 个斷行認 3 類符號**（20261127 P1 擴充）：括號 `（` 前、`／`／`/` 後、分句標點後背（漢字 `、` `，` `；`，括號內外都算，摎連續兩个以上个破折號 `－－` `──`）。標音側對應半形 `,` `;` 摎 `--`。**【讀碼】＋單元測試**
2. **最大个漏網：教典諺語、歇後語**（詞目含 `，`、`；`、`－－`、`──`），六腔合計 **2,049 條**（每腔 255–381 條），詞目中位數 11 字、最長 24 字。Firefox 對這兜符號**無任何斷點**，淨會縮字到下限 10px。粗估（標音 24 音節 ≈ 55–65em，手機可用寬約 320px）縮到下限還係會溢出約 2 倍寬。**P1 已處理（20261127）：用真資料試算，2,046／2,048 條斷得開（1,747 條照標點斷、299 條標音缺標點，照音節數對齊）；剩 2 條標音夾別讀註記抑係格式怪，對毋齊，維持縮字。瀏覽器畫面吂實測。**
3. ~~Firefox 對「斜線兩讀」有兩套邏輯~~ → **P3 已統一（20261127）**：認證 `/` 摎教典 ` / ` 都疊成多層讀音（`expandReadingsForDisplay`）。教典 77 條有 ` / ` 个，76 條疊層；剩 1 條（教典安「因由」`rhǐn / rhiù`，兩隻單音節，音節數摎字數對毋著）維持原樣。**【讀碼】＋真資料試算＋單元測試，吂在 Firefox 實測**
4. 「強制」摎「看空間」兩種語意混用：疊層、變體分行係強制；括號、斜線、頓號斷行係空間毋夠正斷。**【讀碼】**
5. 這份**淨盤點 Firefox 摎 Chrome 系**。Safari／iOS 行 Chrome 路徑（`adjustRubyFontSize` 淨對 Firefox 生效），但 ruby 實際換行位置吂驗證。
