# 雙書寫標註與雙行轉換（Dual-Scripter）

客源翠（HakSpring）與客源翠企盤（HakSpring Kipan）提供「雙書寫標註」與「雙行轉換」功能，讓臺灣客話在諸夏字（漢字）與羅馬字之間可以並列輸入，也能一鍵拆解成上下對齊的兩行文本，方便編寫教材、歌詞對照、語料整理或社群貼文。

> 🛠️ **線上轉換小工具**：[前往雙行文字轉換器 (annotation-converter.html)](annotation-converter.html)

---

## 一、什麼是雙書寫標註？

使用客源翠企盤打字時，可設定同時輸出「漢字＋羅馬字」的並列標註格式；或在編輯既有文稿時，手動撰寫以下任一種雙書寫標註：

| 標註格式 | 範例 |
| --- | --- |
| 圓括號（半形／全形） | `𠊎 (Ngǎi) 識 (sii) 講 (gòng) 客話 (Hàgfa)。`、`客源翠（Hàg-Ngiǎn-Cui）` |
| 方括號（半形／全形） | `無成功 [mǒ sǐin'gúng]`、`無反應［mǒ fàn'in］` |
| 花括號（半形／全形） | `試驗 {Cii-ngiàm} 好 {hò}`、`｛...｝` |
| HTML Ruby 標籤 | `<ruby>𠊎<rt>Ngǎi</rt></ruby>` 或 `<rt>` 簡寫 |

### 在哪裡可以使用雙行轉換？

- **網頁小工具**：[annotation-converter.html](annotation-converter.html)（支援多段落貼上、自動判定或手動切換頂層行、單行複製與全文複製）。
- **macOS 客源翠企盤**：選取文字後按 `⌃⌘T` 原地拆成上下兩行（若宿主程式未提供選取範圍，會自動改讀剪貼簿）。
- **Android 客源翠企盤**：點選工具列雙行轉換按鈕，將輸入框內的雙書寫標註就地轉為兩行。

## 二、轉換與排版規則

1. **首字自動判定頂層**：
   - 第一個有效字詞為漢字時，上方為諸夏字（漢字）行，下方為羅馬字行（`han-top`）。
   - 第一個有效字詞為羅馬字時（如 `Ngǎi (𠊎)`），上方自動改為羅馬字行，下方為漢字行（`rom-top`）。
   - 網頁轉換器亦支援手動鎖定「諸夏字在頂」或「羅馬字在頂」。
2. **羅馬字拼寫忠實保留**：
   - 連字號（如 `Hàg-Ví-Fi`）、詞內空格（如 `gì oi`）、緊湊連寫（如 `dídù`）與隔音撇號（如 `mǒ sǐin'gúng`）皆原樣保留，不擅自拆字或合併。
3. **中立英數兩行並列**：
   - 句中未標註的英數字串或版本號（如 `v0.0.5`）會同時保留在上下兩行對應位置。
4. **多段落對稱保留**：
   - 原本的換行分段會在兩行各自保留，方便整首歌詞或整段課文批次轉換。

## 三、全形／半形標點雙向互換表

轉換器會依各自書寫系統的排版習慣，將漢字行與羅馬字行的標點進行雙向轉換：

### 1. 全形標點 → 半形標點（漢字行轉羅馬字行）

| 類別 | 全形來源標點 | 轉換後半形 | 備註 |
| --- | --- | --- | --- |
| 刪節號 | `……`、`…`、`⋯⋯`、`⋯` | `...` | 含中線刪節號 |
| 雙點刪節號 | `‥` | `..` | — |
| 破折號／連接號 | `——` | `--` | 雙破折號 |
| 破折號／全形減號 | `—`、`–`、`―`、`－` | `-` | — |
| 波浪號 | `～`、`〜` | `~` | — |
| 中點／間隔號 | `·`、`‧`、`・` | `.` | — |
| 逗號／頓號 | `、`、`﹑`、`､`、`，`、`﹐` | `,` | 頓號在羅馬字行轉半形逗號 |
| 句號 | `。`、`．`、`﹒`、`｡` | `.` | 含全形與直排／小字變體 |
| 驚嘆號 | `！`、`﹗` | `!` | — |
| 問號 | `？`、`﹖` | `?` | — |
| 分號 | `；`、`﹔` | `;` | — |
| 冒號 | `：`、`﹕`、`︰` | `:` | — |
| 圓括號 | `（`、`﹙` ／ `）`、`﹚` | `(` ／ `)` | — |
| 方／角括號 | `【`、`〔`、`［`、`〖`、`〘`、`〚` ／ `】`、`〕`、`］`、`〗`、`〙`、`〛` | `[` ／ `]` | — |
| 花括號 | `｛`、`﹛` ／ `｝`、`﹜` | `{` ／ `}` | — |
| 雙引號／雙書名號 | `「`、`“`、`《`、`〝`、`＂`、`﹁` ／ `」`、`”`、`》`、`〞`、`﹂` | `"` ／ `"` | 含直排引號 |
| 單引號／單書名號 | `『`、`‘`、`〈`、`＇`、`﹃` ／ `』`、`’`、`〉`、`﹄` | `'` ／ `'` | 含直排引號 |
| 全形 ASCII 符號 | `／` `＼` `＋` `＝` `＜` `＞` `＆` `％` `＃` `＠` `＊` `＿` `｜` `｀` `＄` `＾` | `/` `\` `+` `=` `<` `>` `&` `%` `#` `@` `*` `_` `|` `` ` `` `$` `^` | 一對一對應半形 |

### 2. 半形標點 → 全形標點（羅馬字行轉漢字行）

以羅馬字為主輸入並附帶半形標點時，漢字行會自動轉回對應全形中文標點：

| 半形來源標點 | 轉換後全形 |
| --- | --- |
| `...` | `……` |
| `--` | `——` |
| `~` | `～` |
| `,` | `，` |
| `.` | `。` |
| `!` | `！` |
| `?` | `？` |
| `;` | `；` |
| `:` | `：` |
| `(` ／ `)` | `（` ／ `）` |
| `[` ／ `]` | `［` ／ `］` |
| `{` ／ `}` | `｛` ／ `｝` |
| `/` `\` `+` `=` `&` `%` `#` `@` `*` `_` `|` `$` `^` | `／` `＼` `＋` `＝` `＆` `％` `＃` `＠` `＊` `＿` `｜` `＄` `＾` |

> **刻意保留不轉換的半形符號**：半形連字號 `-` 與撇號 `'` 在羅馬字拼寫中承擔構詞與隔音功能（如 `Hàg-Ví-Fi`、`sǐin'gúng`），因此半形轉全形時不會將其轉為全形，避免誤傷詞形。
